# 📰 Site — Portal de Notícias

Portal de notícias fictício com layout responsivo, menu mobile com dropdown, submenu por categorias e barra de redes sociais.

## 🚀 Tecnologias

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat&logo=css3&logoColor=white)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat&logo=javascript&logoColor=black)

## ✨ Funcionalidades

- Menu de navegação responsivo com **toggle mobile** via JavaScript
- **Submenu dropdown** por categorias
- Barra superior com links para redes sociais (YouTube, Twitter, Facebook, Google+, RSS)
- Campo de busca no topo
- Layout multi-coluna de notícias

## 📁 Estrutura

```
Site-Portal-de-Noticias/
├── index.html
└── assets/
    ├── css/
    │   └── style.css
    ├── js/
    │   └── script.js
    └── images/
```

## ▶️ Como visualizar

```bash
# Clone o repositório
git clone https://github.com/WilliamBassedone/site-portal-de-noticias.git

# Acesse a pasta
cd site-portal-de-noticias

# Abra o projeto no navegador
# Basta dar um duplo clique no arquivo index.html ou arrastá-lo para dentro do seu navegador
```

> Nenhuma dependência ou instalação necessária.
